# Symbol Canon — Ordinative Sciences Programme (repository edition)

**Status:** v1.0 LOCKED (ratified by the author, 2026-06-11). This file is the repository-level condensation of the programme-wide Symbol Canon; it documents the notation this repository uses from v2.0 onward and its place in the cross-volume canon. The full canon (all volumes, all rulings) is maintained as programme front matter and ships as an appendix of each published volume.

## Tier order

```
OST  (Tier-0 — mathematical-ontological anchor: 𝓘 = ⟨Σ, R, Φ⟩)
 └─ TE Vol 1  (Tier-1 — applied physics of expressions: E = Φ(C, I, K))
     └─ PA, SA  (Tier-2 — this repository)
```

Canon flows downstream. Tier-2 renames before Tier-0/1 does; declared coexistence by operand distinction is legitimate (e.g. TE's pairwise κ(I_a, I_b) beside the coherence vectors 𝓚/𝓚⁵); enum labels do not collide with operators.
